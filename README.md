# Екзаменаційне завдання: "Гра в міста"

## Використані знання

У грі було використано всі навички, які були викладені в програмі **Java Core**, а саме:
- створення класів;
- створення власних винятків та робота з ними;
- створення переліків (`enum`);
- читання інформації з файлу `.txt`;
- робота з колекціями;
- використання бібліотек Swing та AWT.

---

## Правила гри

1. Гравець повинен вводити міста, які є в базі гри, а комп’ютер у відповідь називає місто, що починається на останню літеру міста, введеного гравцем.

2. Після відповіді комп’ютера гравець має ввести місто, яке починається на останню літеру міста комп’ютера.

3. Гра не продовжиться, якщо:
   - гравець введе місто, якого немає в базі гри;
   - місто вже було назване гравцем або комп’ютером.

4. У грі ведеться підрахунок названих гравцем міст:
   - одне місто — один бал.

5. Гравець програє, якщо:
   - вводить у діалоговому вікні слово `"здаюсь"`;
   - після відповіді комп’ютера у базі гри не залишилось міст, що починаються на останню літеру міста комп’ютера.

6. Гравець виграє, якщо:
   - у базі гри не залишилось міст, які починаються на останню літеру міста, введеного гравцем.

## Додавання додаткових міст у гру

За бажанням можна додати нові міста, записавши їх у файл `Cities.txt`, який знаходиться за шляхом:

```text
\Cities_game\src\main\resources\Cities.txt
```
> <ins>***Файл `Cities.txt` обов’язково повинен знаходитись у папці:***</ins>
>
> ```text
> \src\main\resources\
> ```

Записувати міста потрібно через кому.

Приклад:

```text
Київ, Севастопіль, Кривий Ріг, ...
```

## Запуск гри


Для запуску гри потрібна версія Java Oracle OpenJDK 25.0.1.

Запуск гри проводиться через інтегроване середовище розробки IntelliJ IDEA з методу ```public static void main()``` який знаходиться у класі ```public class Main```.
